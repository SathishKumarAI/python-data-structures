# Python Data Structures & Algorithms

## Overview
This repository contains solutions to classic data‑structure and algorithm problems written in **Python 3** and **Go**. Each problem is documented with:
- Problem description (source from LeetCode, etc.)
- Multiple solution approaches
- Code snippets in both languages
- References to external tutorials and discussions.

The documentation resides in the `docs/` folder. Feel free to open a PR to add more problems or improve existing ones.
